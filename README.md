🎓 Student Marks Prediction Using Machine Learning

📌 Project Overview

This project uses Machine Learning regression algorithms to predict students' final mathematics grades based on various student-related attributes. The goal is to explore patterns in student data and evaluate how accurately different ML models can predict final academic performance.

🎯 Objectives

Analyze student academic and personal attributes.

Explore factors associated with students' final grades.

Train multiple Machine Learning regression models.

Compare models using evaluation metrics.

Predict students' final mathematics grades.

📊 Dataset

The project uses the Student Performance Dataset from the UCI Machine Learning Repository.

Dataset: Student Performance

File: student-mat.csv

Target Variable: G3 (Final Grade)

Grade Range: 0–20

The dataset contains student-related attributes such as study time, absences, family background, school information and other factors.
